# -Creating-an-interactive-dashboard

Освоение практических навыков создания интерактивных дашбордов в Python, включая:
1. Интеграцию pandas DataFrame с графическими библиотеками matplotlib и seaborn;
2. Встраивание графиков в окно Tkinter через бэкенд FigureCanvasTkAgg;
3. Реализацию событийно-ориентированной архитектуры (callbacks, event loop);
4. Динамическую фильтрацию, агрегацию и feature engineering «на лету»;
5. Проектирование устойчивого процедурного кода без использования классов.
